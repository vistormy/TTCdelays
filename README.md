### Toronto Transit Commission - Delay Analytics & Real-Time Monitoring

Python • Power BI • scikit-learn • XGBoost • Random Forest  

End-to-end project that ingests >120 k TTC bus & subway delay records, cleans and feature-engineers them (target-encoded routes, cyclic time variables), and trains ensemble classifiers to predict four-level delay severity (~59 % accuracy, 0.83 ROC AUC). A live Power BI dashboard surfaces rush-hour hotspots, directional congestion, and incident causes, giving planners data-driven recommendations for schedule re-tuning, preventive maintenance, and rider communications.
